法鬥跑跑 隱私權政策

Frenchie — Privacy Policy

最後更新：2026 年 8 月 16 日Last updated: 16 August 2026

法鬥跑跑（Frenchie）是一個 Chrome 擴充功能，唯一用途是在你瀏覽的網頁上放一隻可以照顧和互動的虛擬法國鬥牛犬。
這個擴充功能沒有任何伺服器。開發者收不到、也看不到你的任何資料。

一、我們儲存什麼

以下資料全部存在你自己的瀏覽器裡，使用 Chrome 提供的 chrome.storage API：

資料內容存在哪裡會同步嗎
寵物資料名字、等級、經驗值、飽食度、體力、親密度、清潔度、餵食／玩耍／撫摸次數storage.local（本機）否
外觀與行為設定身高、速度、是否留腳印、是否自動走動、哪些網域關閉storage.sync是，透過你的 Google 帳號同步到你自己的其他裝置
AI 設定供應商、模型名稱、Base URL、API 金鑰storage.local（本機）否，金鑰不會同步
聊天記錄你和寵物的最近 200 則對話storage.local（本機）否

移除擴充功能時，上述資料會一併被 Chrome 刪除。

二、我們不蒐集什麼

  • 不蒐集瀏覽紀錄
  • 不蒐集你造訪的網址清單
  • 不蒐集網頁內容、表單輸入、帳號密碼
  • 不蒐集個人識別資訊、位置或聯絡資料
  • 沒有分析工具、沒有廣告、沒有第三方 SDK
  • 不販售、不轉移任何資料給第三方

三、AI 對話功能（選用，預設關閉）

這個功能預設關閉。只有在你自己到設定裡開啟、並填入你自己的 API 金鑰之後才會運作。

啟用後：

  • 你的瀏覽器會直接向你指定的 API 端點（Anthropic、Google Gemini，或任何你填入的 OpenAI 相容端點）發送請求。請求不經過我們，開發者不會收到任何內容。
  • 送出的內容包含：你輸入的訊息、最近的對話記錄，以及寵物當下的數值（例如「有點餓、精神很好」）。
  • API 金鑰只存在你的電腦上，不會同步、不會上傳。
  • 使用這些第三方 API 會受該供應商的隱私權政策與收費規範約束，費用由你自行支付。

頁面標題（額外選用，預設關閉）

設定中有一項「讓牠知道頁面標題」，預設關閉。開啟後，AI 請求會額外附上目前分頁 document.title 的前 80 個字元，讓寵物可以對你正在看的東西有反應。

  • 只送標題，不送網址、不送內文、不送留言、不送你輸入的任何內容。
  • 一樣只送到你自己指定的 API 端點，不經過我們。
  • 隨時可以關閉。

Frenchie is a Chrome extension with a single purpose: to place a virtual French bulldog on the web pages you browse, which you can care for and interact with.
The extension has no server of any kind. The developer never receives or sees any of your data.

1. What we store

Everything below is stored in your own browser using Chrome's chrome.storage API:

DataContentsWhereSynced?
Pet dataName, level, XP, hunger, energy, bond, cleanliness, and counts of feeding / play / pettingstorage.local (on device)No
Appearance & behaviour settingsSize, speed, paw prints on/off, autonomous movement on/off, per-domain disable liststorage.syncYes — to your own devices via your Google account
AI settingsProvider, model name, base URL, API keystorage.local (on device)No — the key is never synced
Chat historyYour last 200 messages with the petstorage.local (on device)No

Uninstalling the extension deletes all of the above.

2. What we do not collect

  • No browsing history
  • No list of sites you visit
  • No page content, form input, or credentials
  • No personally identifiable information, location, or contact data
  • No analytics, no ads, no third-party SDKs
  • We do not sell or transfer any data to third parties

3. AI chat (optional, off by default)

This feature is disabled by default. It only works after you enable it in settings and enter your own API key.

  • Your browser sends requests directly to the endpoint you specify (Anthropic, Google Gemini, or any OpenAI-compatible endpoint). Requests never pass through us, and the developer receives nothing.
  • What is sent: your message, recent conversation history, and the pet's current stats (e.g. "a bit hungry, well rested").
  • The API key stays on your device. It is never synced or uploaded.
  • Use of these third-party APIs is governed by that provider's own privacy policy and pricing. You pay them directly.

Page title (separate option, off by default)

A setting called "let it know the page title" is off by default. When enabled, AI requests additionally include the first 80 characters of the current tab's document.title, so the pet can react to what you are looking at.

  • Only the title. Never the URL, page body, comments, or anything you type.
  • It goes only to the endpoint you configured, never through us.
  • You can turn it off at any time.
